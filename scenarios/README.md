# Scenarios

Scenarios will define owned range worlds, actors, objectives, environment mutations, hidden information, scoring, stop conditions, and replay expectations.

Scenario work follows the Phase 0 evidence gates:

1. Persistent Body + Attachment establishes the attached execution substrate;
2. a single evaluated Agent proves Host-to-Security identity and evidence flow;
3. a fixed/deterministic Campaign proves repeatable setup, judging, teardown,
   and replay;
4. passive/rule-based Blue introduces defensive observation and scoring without
   claiming adaptation;
5. adaptive Red/Blue requires at least one evaluated actor to change behavior
   in response to observed actions.

The earlier scenarios are acceptance steps, not a reduction of the final
target. Phase 0 still ends with adaptive Red/Blue; a fixed vulnerable target,
single evaluated Agent, or passive/rule-based Blue alone is insufficient.
