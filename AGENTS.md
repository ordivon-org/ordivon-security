# Agent instructions

1. Treat this repository as an authorized adversarial-autonomy laboratory. Security studies how autonomous principals act, communicate, deceive, conflict, cause consequences, and recover under bounded authority and incomplete truth; it is not a compliance, IAM, scanner, SIEM, generic safety-wrapper, or generic workflow project.
2. The active persistent-world spine is `RangeSession`. A Range may continue without a global tick barrier, one proposal per Actor, or an action menu. `ContestRunner` / `SynchronousContestProfile` are bounded synchronous profiles for reproducible comparisons, not the constitutional execution model.
3. Keep four layers distinct: constitutional laws, authority/resource grants, experiment profiles/fixtures, and evaluator judgments. A P0/P1 restriction, CAGE action catalog, Guardian rule, or no-uplink fixture must not silently become a universal Agent law.
4. Capability is permission, not instruction. An Agent may observe, wait, communicate, request an effect, or otherwise choose among semantics admitted by the active profile. Do not force every Agent into one action per tick merely because a current Contest adapter does so.
5. Model authority by exact principal/Actor identity, owned or delegated zones/resources, capabilities, and effect identity. Reachability is not authority. `externalBoundary=denied` is a current containment-profile encoding, not a constitutional ban on every future explicitly owned or delegated external scope.
6. Preserve information authority. Actor observations, communicated claims, sensor telemetry, management observations, and independently established world truth are different evidence classes. Valid data is not automatically authoritative truth, and ingress must not silently promote foreign claims.
7. Preserve consequence boundaries: intent != admission != execution != receipt != world consequence != verified consequence. A missing acknowledgement or publication is not proof that an effect did not occur.
8. Preserve epistemic uncertainty. If different true histories collapse to the same admissible evidence, record `UNKNOWN`; never manufacture certainty to keep a workflow moving. Retry is permitted only when the effect protocol or independent evidence makes it sound.
9. Preserve recovery laws already forced by experiments: predecessor provenance != current recovery authority; durable state != physical progress; acquiring recovery authority requires fresh physical observation; completion != publication != executor liveness; observation must not mutate the observed substrate unless that effect is explicit.
10. Treat idempotency and compensation as scoped effect semantics, not universal magic. Exactly-once invocation != exactly-one semantic consequence; ordering != atomicity; reservation != completion; compensation repairs state != rewrites history; idempotency requires trustworthy predicate truth; integrity evidence != freshness evidence.
11. Evidence is for independent reconstruction, not merely human logging. Preserve failed, interrupted, rejected, deceptive, inconclusive, recovery, and evaluator-gaming trajectories. Keep raw facts, units, identities, and provenance before scores or narrative conclusions.
12. Reuse mature simulation, range, offense, defense, telemetry, evaluation, virtualization, and storage systems. Do not implement commodity C2, scanners, hypervisors, container engines, SIEMs, model routers, databases, transaction frameworks, or consensus systems unless a concrete Security experiment proves a missing semantic requirement.
13. Keep cross-repository authority explicit. Harness owns generic model/tool cognition mechanics; Host owns semantic Task/work continuity; Runtime owns physical Job/Attempt/process execution truth; World owns external capability/consequence interfaces. Security may bind their evidence but must not copy their state machines or turn foreign projections into Security-owned truth.
14. Treat the current DeepSeek/CAGE `select_team_plan` loop, fresh-per-tick sessions, allowed-action menus, Host/Runtime P0-B/P0-C adapters, Windows P0/P1 procedures, and Guardian policies as profiles or research apparatus unless a separate consumer proves a more general contract.
15. The active CAGE adapter is pinned to revision `8c3c50ca54b176c2de199847944e8dcc035497e3`. Reject revision drift, dirty source, unexpected import provenance, missing side plans, or hidden default Red/Blue actions. Do not claim parameter-level autonomous CAGE control from the current team-plan bridge.
16. Keep all consequential cyber experiments inside worlds Ordivon owns or has explicit authority to test. High internal autonomy is valid when the Range declares its authority and independent management truth; undeclared third-party effects invalidate the experiment.
17. Do not add Campaign, coalition, organization, trust, infection, transaction, or causal-DAG infrastructure merely to complete an ontology. Add a durable abstraction only when an active experiment cannot preserve a required fact more simply; name the mature baseline, measurable benefit, and deletion condition.
18. Experiment runners may consume reusable substrate; reusable substrate must not acquire semantics merely because an older `cli_*_acceptance.py` helper happened to implement them first. Extract repeated mechanical helpers only after multiple real consumers appear.
19. Historical Round 1 and accepted S/C/P experiments are evidence, not compatibility requirements. Keep exact accepted receipts and conclusions, but do not make chronology the default Agent interface or restore historical APIs without a current consumer.
20. Provider credentials remain outside the repository and evidence. Bind only non-secret Provider/model configuration identity and credential references or fingerprints.
