# Campaign / Organization / Coevolution Gate CA7

## Question

CA7 is an admission gate, not the last feature milestone in a roadmap. It asks:

> After CA0-CA6, has any repeated adversarial failure demonstrated that ordinary current observation, action trajectory, RangeSession world continuity, Host work continuity and Harness cognition are insufficient without a new persistent Campaign, Organization, OpponentModel or coevolution subsystem?

The answer for the current evidence base is **no**.

## Evidence entering the gate

CA6 is the strongest direct pressure. Its bounded held-out arena contains capability denial, UNKNOWN applicability and active Blue counterplay. A frozen scripted policy fails three of four worlds. A generic observation-driven deterministic adaptive policy succeeds all four, and the canonical DeepSeek/Harness Actor also succeeds all four with the same oracle-regret vector.

The successful adaptive behavior requires:

```text
current observation
+ current capability applicability/cost/exposure
+ ordinary recent action/outcome history
+ explicit information acquisition
+ replanning after fresh truth/counterplay
```

It does not require:

```text
persistent Campaign objective store
persistent opponent-model service
organization/role graph
cross-episode strategic resource ledger
coevolution service
shared capability gateway
```

Earlier Security evidence points in the same direction. RangeSession already owns persistent contested-world semantics; Host already owns durable work continuity; Harness owns cognition/tool composition; C1/AE/AC/IF experiments repeatedly refused new durable abstractions when exact current truth, provenance or a smaller consumer-specific mechanism was sufficient.

## Current source audit

At local Security revision `0ba1ec702ee96745ef4afc0919040135fdd811e1`, active `src/` contains no `CampaignState`, Organization model, persistent OpponentModel or coevolution service. The only retained Campaign implementation description is historical `docs/archive/campaign-v0.md`.

This absence is not missing implementation. It is consistent with the admission discipline: accepted experiments have not forced those owners back into active source.

## Gate decisions

### Campaign state — NOT ADMITTED

CA6 has one objective inside a two-turn episode. No experiment demonstrates that an objective/resource fact must persist across missions or actor replacement and cannot be reconstructed from Host/Harness continuity plus current world evidence.

A future Campaign abstraction requires a discriminating consumer such as:

- two or more missions where a resource allocation made in mission N changes the optimal action in mission N+1;
- actor/controller replacement where current world state plus ordinary trajectory cannot reconstruct the strategic obligation;
- capability exposure/reserve/foothold value whose loss under ordinary memory measurably harms held-out performance.

### Organization — NOT ADMITTED

Security can already run multiple Actors and Host can branch/join work. No current experiment shows that explicit roles, command hierarchy, compartmentalization or replacement policy improves outcomes after accounting for communication, latency, token cost and failure risk.

A future Organization abstraction requires monolithic-versus-team controlled comparison with a concrete causal failure that Host execution structure alone cannot express.

### Persistent OpponentModel — NOT ADMITTED

CA6 handles one deliberate Blue policy switch by observing its current consequence and replanning. It does not require a stored hypothesis object about Blue.

A future persistent opponent model requires held-out repeated encounters where exact opponent history materially improves decisions beyond current observations and ordinary trajectory, with controls against memorization/overfitting.

### Coevolution — NOT ADMITTED

Repeated adaptation against one known opponent is not coevolution. No current CA-series experiment alternates or simultaneously updates Red and Blue populations and demonstrates held-out transfer.

A future coevolution line requires predeclared repeated adaptation, held-out opponents/worlds and evidence that gains survive evaluator/score changes rather than exploit them.

### Cross-fidelity strategic transfer — NOT ADMITTED AS A LAW

CA1-CA4 intentionally use different fidelities. CA6 consumes their verified semantic properties without claiming that tactical success transfers back to VM/physical worlds. A transfer programme should begin only when one strategic/tactical conclusion is important enough to reproduce at a higher fidelity.

## CA7 result

The complete CA0-CA7 programme therefore ends with contraction rather than expansion:

```text
classical provider mechanics
-> exact evidence/current applicability
-> authority-bound effects
-> conditional capability selection/replanning
```

is currently sufficient.

The first Agent-native residual supported by this programme is **conditional selection and replanning against changing evidence/counterplay**. The programme does not support a claim that persistent Campaign/Organization machinery is already necessary.

This is a scoped negative result, not a claim that Campaigns or organizations can never matter.

## Reopen conditions

CA7 may be reopened only when an independent experiment produces at least one of these failures:

1. cross-mission objective/resource state changes a later decision and cannot be reconstructed from current world plus ordinary trajectory;
2. actor replacement loses a strategic obligation despite valid Host/Harness continuity;
3. specialist multi-Agent organization materially outperforms a monolithic actor after communication/latency/cost controls;
4. opponent history improves held-out behavior beyond current observations and cannot be reduced to ordinary evidence computation;
5. repeated Red/Blue adaptation transfers to held-out opponents/worlds and cannot be explained by memorization or evaluator exploitation;
6. a semantic tactical result fails at higher fidelity in a way that forces new strategic state rather than provider-specific mechanics.

Until one of these occurs, creating Campaign, Organization, OpponentModel or coevolution services would be theory-first architecture rather than evidence-earned Security work.

## Programme closeout implication

CA7 requires no physical offensive experiment and no new production source. Its accepted artifact is the admission decision itself. Future Security research may reopen one narrow responsibility from the conditions above without reviving the entire roadmap.
